## 🚀 Projeto em Destaque

### [API de Transferências Financeiras](https://github.com/devlmach)
API REST para cadastro de usuários, autenticação e transferências financeiras entre contas.

- Clean Architecture com camadas bem definidas (Domain, Application, Infrastructure, API)
- Autenticação e autorização com JWT
- Testes automatizados com **xUnit** e **Moq**
- Padrão CQRS com **MediatR**
- Containerizado com **Docker**
- Documentado via **Swagger**

**Stack:** .NET 8 · ASP.NET Core · Entity Framework Core · SQL Server · JWT · Docker · MediatR · xUnit · Moq
